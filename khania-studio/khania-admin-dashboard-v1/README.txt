Khania Studio — Admin Dashboard V1

Files:
- admin-dashboard.html
- js/admin-dashboard.js
- css/admin-dashboard.css

Integration:
1. Copy admin-dashboard.html to the website root.
2. Copy js/admin-dashboard.js to root/js/.
3. Copy css/admin-dashboard.css to root/css/.
4. Existing admin-pesanan.html, Supabase config, auth, and API files are not modified by this package.

Important:
- This is a V1 test build.
- Dashboard uses the same Supabase order/payment/brief status logic as admin-pesanan.html.
- The Dashboard is monitoring/navigation only; payment verification and brief workflow actions remain in existing Admin pages.
